# Digital Twin Robotic Arm

## Project Overview
This project presents a 5-DOF Digital Twin Robotic Arm that combines hardware, IoT, Unity visualization, and Machine Learning. The physical robotic arm is synchronized with its digital twin for real-time monitoring and control.

## Features
- 5-DOF Robotic Arm
- 3D Printed Components
- Unity Digital Twin
- IoT Control using ESP8266 and Blynk
- Machine Learning for Joint Angle Prediction
- STL Files and PCB Design
- Project Report
